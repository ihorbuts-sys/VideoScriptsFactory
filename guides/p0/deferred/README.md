# Superseded person studies

The five original folders here preserve the earlier deferred studies. Their replacements keep the same guide IDs and are published from [../renders](../renders/). Current Blender scenes and playback files are in [catalog/p0/animations-light](../../../catalog/p0/animations-light/).

The restored guides use the canonical creator rig. Five front-camera options and three friend-filmed rear-camera options are described in [the character guide report](../../../catalog/p0/people-guides-report.md). These archived files are excluded from API bundles and the gallery.
